# 新規プロジェクト初期化プロンプト

新しいプロジェクトフォルダの中で、Claude Code もしくは Codex の**最初のメッセージ**として
このまま貼り付けてください（ターミナル / VSCode拡張機能 / デスクトップアプリ、
いずれの入り口でも同じテキストで動作します）。

---

あなたはこのプロジェクトの初期セットアップを行います。以下の通りに、
このディレクトリ直下にファイル・フォルダを作成してください。既に存在するものは
スキップし、無いものだけ作成してください。

## 1. ディレクトリ構成

```
./
├── .codex/
│   ├── agents/
│   └── skills/
├── .claude/
│   ├── memory/
│   ├── skills/
│   ├── agents/
│   └── rules/
├── CLAUDE.md
└── AGENTS.md
```

空フォルダはそのままだと git にコミットできないので、各フォルダに `.gitkeep` を
1つ置いてください。

## 2. メモリ運用ルールの作成

`.claude/rules/memory-policy.md` を作成し、以下の内容を書き込んでください
（このプロジェクト専用のメモリ運用ルールです）。

```markdown
# メモリ運用ルール（このプロジェクト専用）

- このプロジェクトの記憶は、必ず `.claude/memory/` 配下の Markdown ファイルにのみ
  保存する。
- **セッション開始時**: 作業を始める前に `.claude/memory/` の中で最新の日付の
  ファイルを読み、前回までの経緯・決定事項・未完了タスクを把握してから
  返答すること。
- **セッション終了時 / 新しいセッションに切り替える前**: そのセッションで
  分かったこと・決めたこと・次にやるべきことを `.claude/memory/YYYYMMDD.md`
  （当日の日付。同日に複数回ある場合は `YYYYMMDD-2.md` のように連番）に
  要約して保存すること。
- `.claude/memory/` 以外の場所（グローバル設定やユーザー単位の記憶など）に
  このプロジェクト固有の情報を保存しないこと。逆に、他プロジェクトの記憶を
  このプロジェクトに持ち込まないこと。プロジェクトをまたいだ記憶の混線
  （例: クライアントAの情報がクライアントBのセッションに混ざる）を防ぐのが目的。
```

## 3. CLAUDE.md の作成

`CLAUDE.md` に以下を書き込んでください。プレースホルダー（`{{ }}`）は
分かる範囲で埋め、不明ならそのままにして後で確認してください。

```markdown
# {{PROJECT_NAME}}

## このプロジェクトについて
- クライアント / 用途: {{CLIENT_OR_PURPOSE}}
- 開始日: {{TODAY}}

## セッション運用ルール
詳細は `.claude/rules/memory-policy.md` を参照。要約:
1. 作業開始前に `.claude/memory/` の最新ファイルを読む
2. 作業終了時・セッション切り替え前に `.claude/memory/YYYYMMDD.md` に要約を書く
3. 他プロジェクトの記憶を持ち込まない・このプロジェクトの記憶を他に持ち出さない

## 拡張ポイント
- `.claude/skills/` : このプロジェクト専用スキル
- `.claude/agents/` : このプロジェクト専用サブエージェント定義
- `.claude/rules/`  : 運用ルール一式
```

## 4. AGENTS.md の作成

`AGENTS.md` を作成し、CLAUDE.md と同内容を Codex 向けに書き込んでください
（見出しの文言以外は同一でよい）。末尾に以下を追記してください。

```markdown
## Codex 拡張ポイント
- `.codex/skills/` : このプロジェクト専用スキル
- `.codex/agents/` : このプロジェクト専用エージェント定義

※ メモリの読み書き先は Claude Code と共通で `.claude/memory/` を使用する
  （ツールを問わずメモリを一本化するため）。
```

## 5. 初回メモリファイルの作成

`.claude/memory/{{TODAY}}.md`（{{TODAY}} は今日の日付、YYYYMMDD形式）を作成し、
以下を書き込んでください。

```markdown
# {{TODAY}} セッションログ

## やったこと
- プロジェクト初期化（ディレクトリ構成・CLAUDE.md / AGENTS.md / メモリ運用ルールの作成）

## 決定事項
- （このセッションでの決定事項があれば記載）

## 次にやること
- （次回セッションで着手すべきこと）
```

---

作成が終わったら、作成したファイル・フォルダの一覧を報告してください。
