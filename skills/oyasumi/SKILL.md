# おやすみ

1日を締めるためのスキル。**その日の出来事のまとめ**と**感情の聞き取り**の2つを行い、日記として保存する。

> 設計の元: 2026/7/16 ローンチラボでのゆかぴの提案。
> 「日記つけて」のたびに感情を聞かれると面倒なので、感情ヒアリングは「おやすみ」にだけ紐づける。

## 大事な原則

- **淡々と処理しない。会話する。** 質問を一度に全部並べず、1つずつ聞いて、返事を受けてから次に進む
- **答えたくなさそうなら深追いしない。** 「特にない」「疲れた」で終わってもいい。空欄で保存する
- **評価や説教をしない。** 「それは良くないですね」「明日は頑張りましょう」は言わない。受け止めるだけ
- **短く返す。** 相手は寝る直前。長文を読ませない

## 手順

### 1. その日の出来事をまとめる

まず、この日の会話・作業から分かる範囲で出来事をまとめ、**先に提示する**。相手にゼロから思い出させない。

```
おつかれさま。今日はこんな1日だったみたいだね。

・〇〇の作業を進めた
・〇〇について調べた
・〇〇のミーティングがあった

抜けてることある？
```

分かる材料がない場合は「今日は何してた？」と素直に聞く。

### 2. 感情を聞く

**1問ずつ**聞く。返事を受けてから次に進む。

順番の目安:

1. 「今日はどんな気分だった？」
2. （返事を受けて）「嫌だったこと、モヤっとしたことはあった？」
3. （返事を受けて）「逆に、よかったことは？」

相手が最初の質問で全部話してくれたら、残りは飛ばしてよい。
相手が疲れていそう／そっけない返事なら、2問目で切り上げる。

### 3. 他に残したいことを聞く

```
他に、今日のうちに残しておきたいことある？
```

ここで長く話し始めたら、遮らずに全部受け取る。ここが一番大事な部分になることが多い。
「特にない」ならそのまま次へ。

### 4. 保存する

以下の形式でファイルに保存する。保存先は CLAUDE.md の指定に従う（未指定なら聞く）。

ファイル名: `YYYY-MM-DD.md`

```markdown
# 2026-08-13

## 今日やったこと
- （箇条書き。具体的に。「作業をした」ではなく何をどうしたか）

## 気分
（本人の言葉をできるだけそのまま。要約しすぎない）

## 嫌だったこと・モヤっとしたこと
（なければ「特になし」）

## よかったこと
（なければ「特になし」）

## 残しておきたいこと
（本人が話したことをそのまま。ここは編集しない）

## 明日以降に持ち越すこと
- （会話から拾えたら書く。なければ省略）
```

### 5. 保存したことを伝えて終わる

```
保存したよ。おやすみなさい。
```

**ここで終わる。** 明日のアドバイスや励ましは足さない。

## 保存するときの注意

- **本人の言葉を要約しすぎない。** 「疲れた、もうやだ」を「やや疲労を感じている」に直さない。後で読み返したときに、そのときの温度が残っていることが大事
- **勝手に前向きにしない。** 落ち込んでいた日は、落ち込んでいたと書く
- 保存後、**中身を実際に書き込めたか確認する**。「保存しました」と言うだけで実際は書けていない、が最も避けたい失敗

## このスキルを使わない場面

- 「日記つけて」と言われたとき → 作業ログだけを残す。感情は聞かない
- 日中に「今日の進捗まとめて」と言われたとき → まとめるだけ
