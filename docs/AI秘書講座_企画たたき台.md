# AI秘書講座 企画たたき台

> 2026/7/16のローンチラボで出た議論を、そのまま企画に落としたものです。
> **決定事項ではなく、叩くための材料**です。違和感のあるところは遠慮なく壊してください。

---

## 0. まず、この講座が答えようとしている問い

Rieが7/16に言った、この一文が出発点です。

> 「AI教えてる人ってさ、議事録作れますとか、日程管理できます、メール自動で送れますとか言うけどさ、**実際そんな使わないじゃん**って思うところとかもない？」

つまり:

- 世の中のAI講座は「AIで何ができるか」を教えている
- でも実務では、Gmailに統一していない人にGmail自動化を教えても使えない
- **その人の仕事の形に合わせて設計できないと意味がない**
- そして、それができるのは人間

**この講座が売るのは「AIの機能」ではなく「その人に合わせて設計する力」。**

## 1. コンセプト案

### 一行で

> AIを"使える"人ではなく、**クライアントの右腕としてAIごと設計できる人**を育てる講座。

### 3本柱（Rieが7/16に挙げたもの）

| 柱 | 中身 | なぜ必要か（7/16の発言より） |
|---|---|---|
| **① AIをどう使っていくか** | 機能の紹介ではなく、目の前の人の業務に合わせて組み方を決める力。CLAUDE.mdとスキルの設計、ログの残し方、自動化するかしないかの判断 | 「AI使えるは当たり前だけど、AIをどうやって使っていくか」 |
| **② 伴走に必要なもの** | ヒアリング力・提案力。クライアントの基準や方針を掴む。属人化させずに引き継げる形にする | 「クライアントさんによって全然違うもんね、基準とか方針が」「そういうヒアリング力もいるし提案力もいるし、それがないとこれからは生き残っていけない」 |
| **③ マインドを整える** | 自分の売りを言葉にする。肩書きを決める。「事務」から脱する。自信を持って言える状態を作る | 「自分がやりたいことじゃないと言葉にならないよね。言ってても自信持てないから、そういうのって伝わっちゃったりもする」 |

**前の時代（＝スキル講座）との違い**:
以前は「LINEの送り方」「LPの作り方」「メールの連携の仕方」でよかった。でも今はそこじゃなくなっている。
> サチ「AIに聞いて分かるみたいな感じになってる」

## 2. ターゲット

7/16の会話から浮かび上がる像:

**主ターゲット**
- 在宅・オンラインで働きたい／すでに働いている女性
- スキルは多少ある。でも「自分が何屋なのか」を説明できない
- 単価が上がらない。クラウドワークス／ココナラで実績作りの安い案件を回している
- AIは触っているが、活かしきれている実感がない

**ゆかぴがまさにこの像です**（本人の同意が取れれば、最初の受講者兼ケーススタディになりうる）:
> 「やってることって事務だけじゃないはずなんだけど、どうしてもなんかさ、探すときには事務って言っちゃう」
> 「交流会でつながった人とは全然繋がってない。私が説明できてないから、向こうからしてみたら何やってる人なん？みたいな感じ」

**副ターゲット**
- すでに案件はあるが、人に渡せなくて自分が詰まっている人（サチさんの「他の人に仕事を依頼・相談できる状態になる」）

## 3. 差別化 — 誰と比べられるか

### 3-1. リモラボ / リモートクラウド

| | リモラボ | この講座 |
|---|---|---|
| 規模 | 10年、会員数多数、LINEステップ配信などマーケが非常に強い | 少人数 |
| 出口 | 認定企業とのマッチングサイト（リモートクラウド） | 未定（後述の残論点） |
| 中身 | 「AIアシスタントを作り」「実践的に在宅ワークで使えるAI」 | AIの使い方 ＋ 伴走 ＋ マインド |

**正面からは勝てない。勝つ土俵を変える。**
リモラボは「スキルを身につけて、認定企業とマッチングする」。仕組みとして強い。
こちらは **「一人ひとりの売りを一緒に作り、少人数で伴走する」**。規模で負けるぶん、密度で差をつける。

> Rie「一人でやってると、時代が変わっても同じところ目指してたりとか、一般的にどう見えているかとかはあまりわからずにやり続けちゃったりするよね。そのためにも人数は必要かもしれないね。いろいろ見て何でも言い合える」

**→ 「何でも言い合える少人数コミュニティ」が売りの中核。**

### 3-2. ノウハウ系のAI講座

サチさんの読み:
> 「ノウハウ系より、やっぱり伴走系のほうが需要あるのかな。自分でやろうと思っても結局怠けたりするけど、それをちゃんと見てくれて、頑張ってとか言ってくれる人とか」

**→ 「教える」より「見ている」に価値がある。** カリキュラムより、報告と確認の場のほうが商品価値が高い可能性がある。
実際、ローンチラボ自体（毎週木曜、宣言→次週に進捗報告）がすでにその形になっている。**自分たちがやっていることをそのまま商品にできる。**

### 3-3. AIスクール勧誘型の"詐欺案件"

これが**いちばん重要な差別化**です。ゆかぴが7/16に実体験を共有してくれた、あの構造。

**向こうの構造**:
1. クラウドワークスで「秘書募集」として出す
2. 面談に行くと「一次面接です」と言われ、AIスクールの名前がさらっと出る
3. クレジットカードの有無を聞かれる
4. 「この面談が通ったら実際の案件の詳細に入ります」＝**スクール受講が案件の条件**
5. LINEなど外部へ誘導

**こちらとの違い（ゆかぴの言葉、そのまま講座の理念にできる）**:
> 「私とかがそういう風に作りたいねって言ってるのは、秘書として学んで、その後に仕事をみんなでやっていこうみたいな話だからさ、**別に隠してないじゃん**。クラウドワークスは隠してるから」

## 4. 透明性の原則（この講座の背骨）

同じ「学んで、その先に仕事がある」構造でも、**隠すかどうか**で詐欺とそうでないものが分かれる。
だから、最初から全部書いておく。

| 明示すること | 書き方の例 |
|---|---|
| 学ぶ場であること | 「これは受講型の講座です」 |
| 仕事の話がその先にあること | 「修了後、一緒に案件をやっていく可能性があります」 |
| ただし仕事を保証はしないこと | 「案件を確約するものではありません」 |
| 金額と期間 | 最初のページに書く。面談で初めて出さない |
| 誰がやっているか | 顔と名前と実績。AI生成アイコンではなく |
| 連絡手段 | どこでやり取りするかを事前に明記。途中で外に誘導しない |

Rieも同じことを言っています:
> 「言い方次第ではもっとうまくできそうなのにね。なんていうの？なんかその損させるんじゃなくてさ」

**→ この「隠さない」を、LPでもアカウントでも明文化して打ち出す。それ自体が信頼になり、詐欺案件で傷ついた人に刺さる。**

## 5. 提供形式のたたき台

7/16の会話から自然に出てくる形:

```
【期間】3ヶ月（10月〜12月）
【定員】少人数（3〜5名？ 残論点）
【形式】
  ・週1回のグループセッション（木曜13:00–14:00 = ローンチラボと同じ形）
     - 前回の宣言に対する進捗報告
     - 詰まっているところの相談
     - 各自のリサーチ・発見の共有
  ・個別の壁打ち（月1回？ 残論点）
  ・Discord等での日常的なやり取り
【アウトプット】
  ・3ヶ月後: 自分の肩書きと売りが言葉になっている
  ・自分専用のAI秘書が動いている（CLAUDE.md ＋ スキル数個）
  ・プロフィール／実績が公開の場に載っている（Wantedly、Instagram等）
```

**特徴として打ち出せるもの**:
- **「AI秘書を一緒に作る」**が具体的な成果物になる（受講者が持ち帰れる資産）
- **講師が3人いる**（Rie＝設計と全体、ゆかぴ＝秘書業務とAI秘書運用、サチさん＝デザインと可視化）。これは強い
- サチさんの「AIオフィス」のような**見える化**が、進捗の可視化としてそのまま使える

## 7. 残論点（決めないと進まないこと）

| # | 論点 | いつまでに | メモ |
|---|---|---|---|
| 1 | **価格** | 9月上旬 | Rieの「リサーチしたい」の主目的。3ヶ月伴走型の相場を調べる |
| 2 | **定員** | 9月上旬 | 伴走の密度が売りなので、絞ったほうが整合する |
| 3 | **講座名** | 9月中旬 | 「AI秘書講座」は仮。"秘書"だとゆかぴの課題（＝事務に見える）と同じ罠にはまる可能性がある |
| 4 | **出口をどう約束するか** | 9月上旬 | 「仕事を渡す」と言うのか言わないのか。透明性の原則に直結する最重要論点 |
| 5 | **ゆかぴ・サチさんの立ち位置** | 8月中 | 受講者？ 講師？ 共同運営？ 報酬はどうする？ **早めに合意したほうがいい** |
| 6 | **集客導線** | 9月中 | Instagram単体か、LINE公式を挟むか |
| 7 | **リモートクラウドをどう扱うか** | 8月中 | 競合として避けるか、むしろ「あそこで登録した人の次」と位置づけるか |

## 8. Rieがやると言った「リサーチ」の具体案

> 「今みんながどうやって講座やっているのか、もうちょっとリサーチしたいなと思ってます」

漠然と見ると終わらないので、見る項目を固定します。3〜5件も見れば傾向は出ます。

**調べる対象**: 伴走型／コミュニティ型の講座（AI系に限らない。コーチング系・起業塾系も含む）

**毎回同じ項目で記録する**:

| 項目 | 見るところ |
|---|---|
| 講座名 / 主宰 | |
| 価格・期間・定員 | LPに書いてあるか、面談まで出さないか |
| 「学び」と「仕事」をどう繋げているか | 保証しているか、匂わせているか、切り離しているか |
| セッションの頻度と形式 | 週1？ 月1？ グループ？ 個別？ |
| 何を成果物として持ち帰らせるか | |
| 集客導線 | Instagram / X / LINE / 紹介 |
| **自分ならここは真似したくない、と思った点** | ← ここがいちばん大事 |
