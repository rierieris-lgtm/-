## 1. AI秘書の作り込み（Rie ↔ ゆかぴ / サチさん参加前）

Rieが「日記をつけるスキル」を作ったという報告から始まり、ゆかぴから設計上の指摘が入った。

### ゆかぴからの指摘（重要）

1. **何が保存されているかを必ず確認する**
   「日記つけて」と言ったときに実際に何が残っているのか、最初のうちは毎回中身を見たほうがいい。
   > 「日記つけてって書いた日記をつけました。とかだけが残されてても意味ないじゃん」

2. **感情を残す仕組みを別に作る**
   チャットのタブごとの記録は仕事の話ばかりで、自分の感情はほとんど入らない。仕事の記録としての日記だけになってしまう。

3. **「おやすみ」に紐づける**
   ゆかぴのAI秘書は、最後に「おやすみ」と言うとその日の感情・嫌だったことを聞いて書かせる仕組みになっている。
   - 聞いてもらって答える、を繰り返す
   - 最後に「それ以外に残しておきたいことがあれば」と促す
   - 毎回「日記つけて」のたびに感情を聞かれると面倒なので、**「おやすみ」という言葉にだけ「1日のまとめ＋感情ヒアリング」を込める**

4. **感情ログの使い道**
   感情が残っていれば、文章を作るときにそこから拾える。**Rieが作りたい講座の壁打ちをClaude Codeでするときにも役立つ。**

→ 実装案は [AI秘書_運用メモ.md](AI秘書_運用メモ.md) と [../skills/oyasumi/SKILL.md](../skills/oyasumi/SKILL.md) に落とし込み済み。

## 5. AI活用と講座の方向性（この日いちばん重要な議論）

### Rieの問題意識

> 「AI教えてる人ってさ、議事録作れますとか、日程管理できます、メール自動で送れますとか言うけどさ、**実際そんな使わないじゃん**って思うところとかもない？」

- LINEやメッセージも使っていて、Gmailに統一していないから使えない
- メールを自動で送られるのは怖い（読んで整理してくれるほうはまだ使える）

### 結論として出てきた考え

- **人に合わせて作るからこそ、人間が入る意味がある**
- クライアントによって基準も方針も全然違う → **ヒアリング力と提案力**がないと生き残れない
- 「AI使えるからいいでしょ」では関係性が続かない。**その人の感情や「ここではこう言うだろうな」を分かっている人が間に入る必要がある**
- 完全にAIそのままの見た目だと誰でも嫌だと思う

### 講座に入れたい3つ（Rie）

前は「スキル」の話でよかった（LINEの送り方、LPの作り方、メールの連携の仕方）。でも今はそこじゃなくなってきている。

1. **AIをどう使っていくか**（使えるのは当たり前、その先）
2. **伴走するために必要なもの**
3. **マインドを整える**

> Rie「今みんながどうやって講座をやっているのか、もうちょっとリサーチしたいなと思ってます」

### サチさんの読み

> 「ノウハウ系より、やっぱり伴走系のほうが需要あるのかな。自分でやろうと思っても結局怠けたりするけど、それをちゃんと見てくれて、頑張ってとか言ってくれる人とか」

### Rieの補足

一人でやっていると、時代が変わっても同じところを目指し続けてしまう。一般的にどう見えているか分からずにやり続けてしまう。
→ **何でも言い合えるコミュニティ / 一緒に仕事できる人が必要。**

## 7. サチさんの「AIオフィス」共有（遊び / でも示唆が大きい）

Xで流行っている「AI社員・AIオフィスの可視化」を、noteの有料記事（980円 ※ 田和也さん ※ のアカウント）を参考にClaudeで作った。

- **Claude Code / Codex / Antigravity** それぞれの作業状況を1画面で見られる
- 何をやっているかが全部出る。終わったら休憩室に行く。起動していないものは寝ている
- **セッション使用量**もリアルタイムで表示（いちいち確認しに行かなくていい）
- 数分おきに自動更新。ファイルを開いておくだけ
- 毎週のタスクをお願いしておいて自分が忘れる、が防げる

**Antigravity について**: Googleが出しているClaude Codeのようなもの。無料で使えるので、Claude Codeにいきなり課金する前はこれを使っていた。自分専用の公式LINEに毎日のタスクや、頭に置いておきたい言葉を配信する遊びもしていた。

**Fable 5 について**: 気が利く。言っていないことも先回りして作ってくれる。ただしトークンを消費するので、文章を考えるだけなら不要。ゲーム開発・アプリ開発向き。

**Rieの反応（ここが大事）**:
> 「言い方も大事だね。そうやって社員が動いてくれてます、5人いて、とか言うとすごい興味わく」

**→ 講座やアカウントの発信で使える見せ方。「AI社員が5人働いています」は強い。**
